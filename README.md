# Md Asif Rahman - Interactive Scrollytelling Experience

A high-performance, cinematic, scroll-driven interactive web experience built with HTML5 Canvas, modern CSS glassmorphism, and linear interpolation (Lerp).

![Screenshot Preview](asifrahman-jpg/ezgif-frame-001.jpg)

## 🌟 Features

- **240-Frame Canvas Engine**: Silky smooth frame scrubbing synchronized to user scroll gestures with `requestAnimationFrame` and linear interpolation.
- **HiDPI Retina Ready**: Crisp, high-resolution rendering on modern displays.
- **Glassmorphic Story Milestones**: Floating story narrative cards that fade in and out at key scroll waypoints.
- **Interactive Control Dock**:
  - Auto-play / Pause toggle (continuous video-like playback)
  - Interactive timeline scrubber slider
  - Aspect ratio mode toggle (Cinematic Cover vs 16:9 Letterbox)
  - Web Audio ambient atmospheric sound synthesizer
  - Fullscreen toggle
- **Keyboard Shortcuts**: Space (Play/Pause), Arrow keys (Step frames), F (Fullscreen), M (Mute).
- **Zero Heavy Dependencies**: Pure vanilla HTML5, CSS3, and modern JavaScript.

## 🚀 Getting Started

### Local Browsing
Simply open `index.html` directly in any modern web browser.

### Local Server
Run with Node.js:
```bash
node local-server.js
```
Then visit `http://localhost:3000` in your browser.

## 🌐 Deploy to Vercel / GitHub Pages

This is a 100% pure static web application. It deploys out-of-the-box on **Vercel**, **Netlify**, or **GitHub Pages** with zero configuration.
